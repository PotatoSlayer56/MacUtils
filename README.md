![Modrinth Downloads](https://img.shields.io/modrinth/dt/macutils) ![Static Badge](https://img.shields.io/badge/Minecraft_Version-26.1.2-blue)

## Features
### Commands
- `/autofeed`: toggles autofeed ***For BigMac and Custom ranks only***
- `/lockpitch <pitch>` sets the pitch lock to the specified value
- `/lockyaw <yaw>` sets the yaw lock to the specified value
- `/customcommand <number>` runs the custom command specifies by the number ***Set custom commands in config***
- `/admessage` sends a ad message for macbox.minehut.gg ***Only use in MineHut lobby***
### KeyBinds
- `/ec`
- `/trash`
- Open Config Screen
- Custom Commands 1-5 ***Customisable in config screen***
- Lock / Unlock Pitch
- Lock / Unlock Yaw
